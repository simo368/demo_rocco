# Brand Name — vertical book variation

Open `index.html` in a browser. This is a separate version; the original grid site remains in `outputs/fashion-site`. It is self-contained and has no build step or external dependencies.

## Replace before launch

- Change `BRAND NAME` in `index.html` to the approved name.
- Replace the short About copy with approved brand information.
- Replace `Product 01–03`, the `€ —` price placeholders, and the generated placeholder images.
- Connect the Join form to the chosen email service. The preview intentionally does not store or send addresses.
- Connect product data to Shopify when checkout is ready. The current catalog model already keeps product ID, handle, price, currency, availability, and purchase state separate; there is no cart or checkout in this preview.

The visual language uses an original editorial hero photograph and an original three-panel apparel image. The only external reference is the high-level product-first, minimal-navigation fashion experience described in the brief.

## Interaction

The hero photograph stays pinned behind the opening scene. Product pages scroll upward one over another like a vertical book, with a gentle overlap on touch and desktop. The hero image follows pointer and touch position by a few pixels, and the main lower sections reveal once while scrolling. Every motion is reduced automatically when the visitor enables the operating system's reduced-motion preference.
